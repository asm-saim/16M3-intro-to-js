========================
JavaScript Number Operations
========================

# Adding Numbers
var candy = 60;
var orange = 300;
console.log(candy + orange); // 360

# String + Number (Concatenation)
var mango = "200";
console.log(orange + mango); // 300200

Reason:
- If one value is string, JS converts everything to string and joins them.

# parseInt()
Converts string to integer.
var strawberry = parseInt("400");
console.log(orange + strawberry); // 700

# parseFloat()
Converts string to decimal number.
var avocado = parseFloat("25.5");
console.log(strawberry + avocado); // 425.5

# Conversion Summary
parseInt("400")    -> 400
parseFloat("25.5") -> 25.5

# Floating Point Problem
var number1 = 0.1;
var number2 = 0.2;
var total = number1 + number2;
console.log(total); // 0.30000000000000004

Reason:
- JavaScript uses binary floating point storage

# toFixed()
Limits decimal places (returns STRING)
console.log(total.toFixed(2)); // 0.30

Convert back to number:
console.log(parseFloat(total.toFixed(2))); // 0.3

# Infinity
var num = 50 / 0;
var numNegative = -50 / 0;
console.log(num);        // Infinity
console.log(numNegative); // -Infinity

# Special Values
1. Infinity
2. -Infinity
3. NaN (Not a Number)

Example:
console.log("abc" / 2); // NaN
